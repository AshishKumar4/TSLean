# Compiler Trust Policy

These rules apply to both compiler directions. Lean-to-TypeScript proof certificates add stronger obligations; they do not weaken these rules.

1. Compilation is total over its declared input type. Failure returns typed diagnostics. No caught failure becomes a placeholder or guessed implementation.
2. Printed code comes from typed syntax nodes. No raw-source constructor bypasses the IR and printer.
3. Placeholder and trusted-base audits operate on parsed structure, not source-text patterns.
4. Comment content cannot introduce declarations or change generated semantics.
5. The compiler fabricates no language instances or laws. JavaScript equality, ordering, conversion, time, and effects use modeled operations.
6. Platform behavior enters through an explicit capability, formal model, or named runtime assumption. It never enters as an untracked axiom.
7. Every exported Lean theorem passes the transitive axiom gate. The closed base allowlist is `propext`, `Classical.choice`, and `Quot.sound` unless a reviewed theorem family narrows it further.
8. Every analysis declares a complexity bound and has a scaling test that fails when the bound is exceeded.
9. Every admitted Lean-to-TypeScript IR operation names its source semantics, target semantics, lowering theorem, emitted runtime symbol and body digest, and exact conditional runtime assumptions.
10. Generation fails when a reachable operation lacks its proof or certificate record.
11. A manifest binds the semantic IR, proofs, certificates, compiler, runtime, generated bytes, source maps, and exact toolchains.
12. Differential tests are counterexample searches. They are never reported as refinement proofs.
13. External assumptions are obligations to discharge with a certified adapter, runtime proof, or exact conformance evidence. They are not fallback branches.
14. A generated artifact is publishable only when every required proof, certificate, assumption record, and freshness check is current.
15. A synthesis candidate is publishable only when every proof and model obligation is closed. Rejected candidates retain diagnostics, not authority.
